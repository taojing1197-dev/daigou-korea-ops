# daigou-korea-ops

A Codex skill for safely operating a Korean proxy-shopping project: source-aware product processing, image and copy workflows, storefront synchronization, frontend changes, and validation.

## Install

Copy this repository to your Codex skills directory, then start Codex in the project workspace. The skill expects the project to provide its own `AGENTS.md`, scripts, and data contracts.

## Safety

The workflow preserves unrelated Git changes, requires source-traceable product claims, and does not authorize publishing, paid generation, account actions, or production data changes.
